# Babblebird

Babblebird is where open source projects get translated. Install its GitHub App on a repository and it finds the Fluent files, groups them into areas the way the project is built, lets people translate them with checks, a glossary, earlier translations and screenshots at hand, and sends the translations back as commits.

It runs at [babblebird.dev](https://babblebird.dev). How it works is in [docs/](docs/): [design](docs/design.md), [repository layout and babblebird.toml](docs/repositories.md), [screenshots](docs/screenshots.md), [running it](docs/running.md) and [scale and cost](docs/scale.md).
