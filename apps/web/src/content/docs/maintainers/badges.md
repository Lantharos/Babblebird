# Badges

Every public project has a badge that shows how much is translated, for its README:

```markdown
[![Translations](https://babblebird.dev/api/badge/owner/repo.svg)](https://babblebird.dev/p/owner/repo)
```

Add `?lang=de` to show one language. The badge is green from 90%, amber from 60% and red below, and shows the project's icon. It's cached for ten minutes.

The project's **What's missing** page lists every language with how many strings are missing, need review or have problems, and has the badge ready to copy.
