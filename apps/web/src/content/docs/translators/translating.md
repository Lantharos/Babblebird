# Start translating

1. [Sign in](/sign-in) with GitHub, Google, a passkey or a code sent to your email. Accounts with the same verified email address are one account, and you can link GitHub later from your settings.
2. Open [Help translate](/projects). Pick the languages you translate into in [Settings](/settings), and the list shows how far each project is in them, with the ones that need you most first.
3. Open a project, pick your language, then an area. An area is one part of the project, such as an app, an extension or a part of the desktop.
4. The editor opens on the first string that has no translation yet. Write it and press <kbd>Ctrl</kbd> <kbd>Enter</kbd>; the next one opens.

Whether your translation goes straight in depends on the project. Most let anyone signed in translate. Some only let the people they've added translate, and everyone else can suggest; a translator or reviewer then picks a suggestion up.

Your translations reach the project's repository in small batches, credited to you in the commit if you've signed in with GitHub.
