# Reviewing

Reviewers can approve translations. Approving says a translation was checked by someone fluent; it doesn't change what goes to the repository.

- Pick **Review** in the editor's filter to see translations that need a look: ones whose English changed after they were translated, and ones imported from a changed source. The editor shows what the English said before.
- Edit if needed, then press <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Enter</kbd> to approve and move on.
- **Problems** lists translations a check flagged: missing placeables, punctuation that doesn't match, spacing, glossary terms.
- Suggestions from people who can't translate in the project, and translations kept aside after a conflict with the repository, show up next to the string. Use one or dismiss it.

A project's maintainers decide who reviews, for which languages and which areas. See [People and roles](/docs/people-and-roles).
